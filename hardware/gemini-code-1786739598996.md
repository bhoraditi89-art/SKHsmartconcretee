# 🛠️ Hardware & Physical Prototype Specifications

This folder contains the physical dimensions, mold specifications, and IoT wiring schematics for the Smart Concrete 1x1x1 prototype.

---

## 1. The 1x1x1 Concrete Mold Specs
To test this in a hackathon environment, we use a standard physical prototype mold. You can build this out of laser-cut acrylic (for visibility) or coated plywood.

*   **Internal Dimensions:** 1 foot x 1 foot x 1 foot (30.48 cm x 30.48 cm x 30.48 cm).
*   **Material:** 8mm clear acrylic (allows judges to see the embedded fiber optic cables leaving the block).
*   **Grid Spacing (Fiber Optics):** Holes are drilled at 2-inch intervals on the side panels to weave the fiber optic cables in a cross-hatch matrix before pouring the concrete.
*   **Concrete Mix Ratio (Prototype):** Standard M20 grade (1 part cement : 1.5 parts sand : 3 parts aggregate) + 5% volume micro-encapsulated *Bacillus subtilis* bacteria.

## 2. Circuit & Wiring Schematic
For the hackathon, we are reading the optical strain using an Optical Interrogator module (or simulating the optical feedback via a high-precision analog amplifier). 

### Pinout Connections
| ESP32 Pin | Component | Wire Connection | Function |
| :--- | :--- | :--- | :--- |
| **3V3** | Sensor Amp | VCC (Red) | Powers the optical interrogator |
| **GND** | Sensor Amp | GND (Black) | Ground connection |
| **PIN 34 (ADC1)**| Sensor Amp | OUT (Yellow) | Reads the raw analog strain data |
| **PIN 2** | Status LED | Anode (+) | Flashes blue when sending MQTT data |
| **PIN 4** | Buzzer | Anode (+) | Local alarm when a crack is detected |
